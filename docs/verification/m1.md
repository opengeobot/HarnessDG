## 3. 偏差记录（规格与实现的差异及理由）

1. **限流实现替换**：规格写 Bucket4j+Redis；实际用自研固定窗口（Redis Lua `INCR+EXPIRE` 原子计数），Redis 不可用时 `ResilientRateLimiter` 降级 `LocalRateLimiter` 保守模式。理由：固定窗口语义与规格行为一致且依赖更少；07 章未强制具体库。
2. **repository_collaborators 顺延阶段 2**：端点语义绑定仓库资源，提前交付会引入空表桩代码。
3. **Docker 29 兼容**：Testcontainers 1.21.3（BOM 置于 spring-boot-dependencies 之前）+ `modules/app/src/test/resources/docker-java.properties` 固定 `api.version=1.44`。升级 Testcontainers 2.x 后可移除。
4. **client-ip-header 默认关闭**：仅在可信反向代理后配置（application.yml 默认空），测试经 DynamicPropertySource 启用 `X-Test-Client-Ip`。符合 07 章防伪造要求。
5. **测试客户端禁用 httpclient5 自动重试**：httpclient5 默认按 Retry-After 自动重试 429/503，会“消化”限流响应；`BaseIntegrationTest` 统一 `disableAutomaticRetries()`。
6. **Testcontainers withReuse 本机未生效**：环境不支持 reuse，容器每次运行重建；不影响正确性，仅影响测试时长。
7. **Hikari 池测试配置 30**：REQUIRES_NEW 嵌套事务（业务 + LoginGuard + 审计）并发时单请求最多占 3 连接，测试显式扩容避免饿死。
